# 野战（3D，仿骑砍战团）

独立场景（不依赖 `scripts/` 里的任何东西），既能单独运行，也已接入大地图的遭遇战和匪巢。

```bash
cd client
./battle.sh                          # battle/sample_setup.json：周（你）vs 燕（拓延骁）
./battle.sh --terrain=hills --night  # 换地形（plains/meadow/steppe/hills/forest/taiga/desert/dunes/snow/marsh/mountain）、夜战
./battle.sh --auto                   # AI 代你作战（观战）
./battle.sh --setup=my.json --out=result.json
battle/tests/run_battles.sh 6        # 回归：无画面并行跑 6 场，打印胜负/伤亡/战斗统计
```

## 操作（按战团）

| 键 | 作用 |
|---|---|
| 鼠标 | 转视角 |
| **移动鼠标的方向 + 按住左键** | 举起武器（可以一直蓄着），**松开**挥出。鼠标往上 = 劈砍，往左/右 = 横砍，往下 = 刺 |
| **右键（按住）** | 格挡。方向同样由鼠标移动决定：挡左边来的就往左。盾牌任何方向都能挡，还能挡箭 |
| 准星旁的小三角 | 当前出招方向（金色 = 已举起，外圈 = 蓄满）；格挡时变蓝 |
| 弓/弩 | 按住左键拉弓（准星圈越收越小 = 越准），松开放箭；移动、骑马会变不准。弩射完要上弦，**马上不能上弦**（只能射出事先上好的那一发） |
| WASD | 走（Shift 慢走）。**骑马时**：W 催马、S 勒马、A/D 转向；马有惯性 |
| 滚轮 | 换武器（弓 → 主武器 → 副武器） |
| 1 / 2 / 3 / 0 | 选中步兵 / 射手 / 骑兵 / 全军 |
| F1–F9 | 原地驻守 · 跟我来 · 冲锋 · 就地站住 · 撤退 · 前进十步 · 后退十步 · 靠拢 · 散开 |
| Tab | 撤离战场（附近有敌人时不行）；你倒下后 = 让部下加速打完 |
| Backspace | 战场全图：敌我每个人的位置、你下令驻守的地点 |
| Esc | 释放鼠标 |

## 规则从哪来

全部在 `server/rules/battle.toml`（和大地图同一套「规则即文档」），客户端用一个小 TOML 解析器直接读：

- `[combat]` 出招/挥出/收势时间、磕碰（太近打不出伤害）、**速度加成**（骑兵冲锋、迎着敌人挥砍更疼）、格挡角度、硬直、击倒
- `[armor]` 砍/刺/钝三种伤害对护甲的减免
- `[weapons.*]` `[shields.*]` 刀、骨朵、长斧、长矛、戟、马槊（**端枪冲刺**：马速够快自动平端）、弓、强弓、骑弓、弩
- 持械规则（`hands` / `mount` / `mount_reload`）：手里是弓弩或双手兵器（长斧、长戟）时，盾背在背上——不能举盾格挡，但能挡住背后射来的箭；
  长斧、强弓、大橹马上用不了（换武器时跳过，骑兵没有能用的近战兵器就自动配短刀）；弩在马上不能上弦
- `[loadout.*]` 每个兵种的配装：默认表 + 文化覆盖（周：弩与戟；燕：甲骑具装；蜀：藤牌与连弩；柔：骑射手……），土匪、中立按兵种 id
- `[horse]` 马速、惯性、转向、冲撞（撞倒步兵、陷进人群会被拖慢）
- `[morale]` 伤亡过半后逐个溃逃，等级越高越坚定，主将在场更稳
- `[ai]` 反应时间、格挡概率（随等级）、围攻上限、射程、骑兵冲过后多远回马
- `[battle]` 同时在场人数（战团的 battle size），其余作为援军分波上场

兵种名、等级、类别来自 `server/rules/units.toml`，id 和大地图服务器完全一致（`zhou_inf3`、`yan_cav4`……）。

## 和大地图的接入（已接入）

像战团一样：在大地图上遭遇敌军时，菜单里有两个选择——

- **亲自率军冲锋 / 亲自上阵迎战（进入战场）**：切到 3D 战场，你和部下（以及附近赶来助战的友军）对阵敌军；
  打完点「返回大地图」，每个兵种的阵亡、重伤、溃逃都会写回大地图，俘虏、战利品、名望、擒获敌将照常结算。
- **让部下进攻 / 迎战（自动结算）**：和以前一样由大地图直接结算。

攻打**匪巢**同样可以「亲自带精兵步战突入」：带上你最精锐的十几个人（`balance.toml [bandits] hideout_team`），全体下马。

你本人和有名有姓的将军在战场上只会被打昏，不会阵亡（同战团）。你亲自上阵时用的是装备栏里身上那套
（按 I；物品在 `server/rules/items.toml`，引用本文件的 `[weapons.*]` `[shields.*]` 再覆盖几项数值）。
开局装备随家世（`world.toml [backgrounds.*] equip`）。头部中招按头盔的护甲算，身体按身甲；坐骑决定马速、马体和马铠。

流程：服务器生成 setup（双方兵力按自动结算同样的规则召集，地形取所在格子，昼夜取当前时辰）→ 菜单类型 `battle`
→ 客户端把大地图藏起来、在同一个窗口里加载 `battle.gd`（`embedded = true`）→ 打完 `closed(result)` →
`POST /player/battle` → 服务器 `warfare.apply_battle_result`（或匪巢的 `apply_hideout_result`）。

单独运行（不连大地图）仍然可以：`./battle.sh`，读 `--setup=` 的 JSON。

### setup / result 格式

输入 `setup`：

```json
{"terrain": "hills", "seed": 7, "night": false, "player_side": 0, "dismounted": false,
 "sides": [
   {"name": "你的部队", "color": "#3f6fb0",
    "hero": {"name": "你", "player": true, "troop": "zhou_cav3", "loadout": {"melee": ["sword"], "shield": "round", "horse": "horse", "armor": 26}},
    "troops": {"zhou_inf2": 14, "zhou_arc2": 12}},
   {"name": "拓延骁的部曲", "color": "#4f7fd8", "hero": {"name": "拓延骁", "troop": "yan_cav4"},
    "troops": {"yan_cav3": 12, "yan_inf2": 12}}]}
```

输出：

```json
{"winner": 1, "how": "", "player_side": 0, "time": 96,
 "sides": [{"name": "...", "hero": "wounded",
            "troops": {"zhou_inf2": {"killed": 4, "wounded": 5, "routed": 0, "fine": 5}}}, ...],
 "stats": {"swings": 560, "blocked": 82, "arrows": 400, "couch": 30, ...}}
```

`how = "retreat"` 表示玩家撤离（敌军不追俘你，但你留在战场上的伤亡照算）。

## 实现

| 文件 | 内容 |
|---|---|
| `scripts/battle.gd` | 部署、援军、命令与阵型、士气溃逃、战斗结算（格挡判定、速度加成、护甲）、箭矢、结果 |
| `scripts/agent.gd` | 单个士兵：状态机（举起/挥出/收势/格挡/硬直/倒地）、方向姿态（和画面共用，所见即所击）、骑马惯性、端枪、冲撞 |
| `scripts/ai.gd` | 士兵 AI：选目标（围攻上限）、出招方向（避开身边友军）、反应式格挡、射手提前量与抛物线补偿、不往友军里射、骑兵冲阵回马、骑射绕圈 |
| `scripts/player_ctrl.gd` | 第三人称相机、按键、鼠标方向出招 |
| `scripts/field.gd` | 高度图地形（按大地图地形类型着色）、树、天空 |
| `scripts/rig.gd` | 程序生成的人和马（方块风格，占位美术）与程序动画：两节手臂/腿用两骨 IK 解手肘膝盖、按移动方向迈步、躯干扭转俯仰、马的小跑/疾驰步法、倒地与阵亡 |
| `scripts/sfx.gd` | 启动时合成的音效（不用音频文件）：破风、金铁交鸣、盾响、砍中、钝击、弓弦、中箭、马蹄 |
| `tests/pose_lab.tscn` | 动作检查：一排士兵各做一个动作（待机、走、跑、横砍、上劈、刺、格挡、双手斧、射箭、倒地、阵亡、骑马），`--cam=3,6 --shots=路径@秒,…` 截图 |
| `scripts/toml.gd` `scripts/rules.gd` | TOML 读取、兵种表与配装 |

士兵不用物理引擎（120 人的胶囊体互相碰撞太慢）：位置按速度积分、贴地，重叠时由网格推开。整场约 6 ms/帧（120 人）。

### 动作（程序动画）

没有找到能直接拿来用的开源骑砍式战斗（OpenMB 是 GPL 的 C#/Ogre 引擎复刻），所以动作借鉴 Veloren 那种「代码驱动骨骼」的
思路自己写：每个出招分 **蓄力 → 出手 → 收势** 三段，每段对手臂方向、躯干扭转/俯仰、下蹲、前冲步做插值。
姿态由 `Agent.pose()` 算出，**命中判定和画面用同一套数学**（肩膀位置随躯干转动，手的位置 = 肩 + 手臂方向 × 伸展），
所以看到的刀光就是判定的刀光。手肘、膝盖、脚、马腿只是画面，在 `rig.gd` 里解。

骨骼摆放在**渲染帧**里做（不在物理帧里），近处每帧、远处和镜头背后隔几帧，所以掉帧不会拖慢模拟：
240 人的战斗约 37 帧/秒（之前 30）。

### 擂台比武

城里的「上擂台比武」：一对一、木兵器（随机发一套：木刀盾、包头枪、骨朵藤牌、长斧），对手是当地的兵，你连赢越多对手越强
（`server/warlords/warfare.py` 的 `arena_setup`）。战场上围一圈木栅，没有溃逃；Tab = 认输。结果回到大地图：赏钱、名望、赌注。

### 攻城（登城战）

围城时攻城器械（云梯）造好后，大地图会问你：**亲自率军登城**（进入 3D）、下令强攻（自动结算）、或再围一天。
亲自登城时（`warfare.py` 的 `siege_setup`，setup 里带 `"siege": {"defender": 1, "walls": 城墙等级, "ladders": 架数}`）：

- 战场中间横着一道城墙（高 5–8.5 米，随城墙等级），外沿有垛口；攻方一侧搭着 3–5 架云梯，城内有几道马道（石阶）下城。
  这些高度都折算进 `field.height_at()`：人能站在城头、顺着云梯爬上去，箭会钉在墙面和垛口上；人不能走上墙面，
  AI 不会从城头、云梯边上掉下去（只有你自己可以跳下去，落差大会摔伤）。
- 寻路：`field.waypoint()` 把「从城外到城上 / 城内」拆成「走到最近的云梯脚 → 顺梯爬到顶」，下城同理走马道；
  爬云梯很慢（`battle.toml [siege] ladder_speed`）。
- 守军：射手直接站上城头分散在垛口后，步兵分守各个梯头（每个梯头 7 人，多出来的在马道下待命），不追下城；
  守军不溃逃（死守）。城上砍城下的人有居高临下的加成（`height_edge`）。
- 攻方 AI：射手在城下 34 米处驻守放箭，箭用完了再冲；步兵直接冲向云梯。你可以照常下令。
- 结果回到大地图：伤亡分摊到城下各部、守军、民兵和城里的将军；攻下了就和自动强攻一样易主、论功请封，失败则撤围。

大致平衡（AI 对 AI）：同等兵力时攻方伤亡是守方的 4 倍左右，必败；兵力二比一时攻方能拿下，但损失不小。

### 城镇漫步（进城、进村）

在城镇 / 城堡 / 村庄的菜单里选「在城中走走（3D）」，就像战团的「在街上走走」：用同一套人物、操作和镜头，
走进按这座城的种子生成的街巷（`scripts/town.gd`：城墙和城门、16 米一格的街坊、广场集市、北端的府衙、东边的擂台、
客舍、牢城；城堡是小城墙 + 主堡 + 校场；村庄是围着水井散落的十几户人家和田地）。房屋折算成 `field.height_at()` 里的高块，
人走不进去，不需要物理碰撞。

菜单里能办的事都由一个人站在相应的地方（服务器 `warlords/walk.py` 按当时的菜单选项生成）：市令在集市，募兵的伍长和志愿兵在广场，
擂台主在擂台边，狱卒在牢城门口；**守将和在城里的将军在府衙大堂里**，**店家和赎金掮客在酒肆里**。

- **室内**：走到府衙（城堡是主堡）或酒肆门口按 F 进门。大堂是一间长厅：两排红柱、尽头高起的台子和主座、旗帜、灯，
  守将站在台前，门口有卫兵；酒肆有柜台、桌凳，店家在柜台后，几个酒客围着桌子，跟他们搭话能听到最近的传闻
  （服务器把编年史里最近的大事——宣战、议和、召集军团、流寇落草——改写成「听说前两天，……」）。
  室内镜头不会穿墙、不会顶到房梁。走到门口按 F 出门，回到街上的那扇门前。
- **在街上直接办事**：走到人跟前按 F（同一个人有几件事时按 1–9），对话就在 3D 场景里进行——用的是大地图同一个菜单面板，
  直接和服务器通信：和将军交谈（话题、回答、自由输入都有）、打听并接下差事、招募（志愿兵跟你走了，广场上的人就少了）、
  在集市摊位前买卖、卖俘虏、提审俘虏、处理封地。对话时人物停下、互相看着，镜头越过你的肩膀对着对方；Esc 或「告辞」结束对话，回到街上。
  只有必须回大地图的事（上擂台、休整、离开）才会结束漫步。
- 路人在街口之间闲逛，按 F 可以搭话；城门口有卫兵。走到城门按 F，或按 **Tab**，回到城镇菜单。夜里进城就是夜景。

单独运行：`godot --path client res://battle/walk.tscn -- --setup=res://battle/sample_walk.json`（`--topdown` 从空中看布局，`--room=hall` / `--room=inn` 直接进屋）。单独运行时没有服务器，选了事就结束漫步。

### 难度（仿战团的选项，客户端「设置」里调）

| 选项 | 作用 |
|---|---|
| 你受到的伤害 | 1/4、1/2、全额：你本人和坐骑受到的伤害 |
| 友军受到的伤害 | 1/4、1/2、全额：你的部下和友军 |
| 战斗 AI | 差 / 一般 / 好：格挡概率、反应时间、出招间隔、射手误差（`battle.toml [difficulty]`） |
| 战斗速度 | 最慢 … 最快：出招、收招快慢 |
| 格挡方向 / 攻击方向 | 手动（鼠标方向）或自动 |
| 战场规模 | 同时在场人数 40–300 |

面板上显示「战斗难度 %」。单独运行战斗时可用 `--ai=0..2`、`--player-damage=0.5`、`--combat-speed=1.1`。
