## chat · yan · ["ruler"]

- ✗ 足下肯与孤说这些，是把我当朋友了。燕地风大，话也直，别嫌。（自称忽「孤」忽「我」，前后不一；且「话直」之意与第1句重复，留第1句更好。）
- ✎ 坐下说话。{here}没有那么多讲究，有酒就喝，有敌就砍。
  → {here}不比周人的朝堂，没那么多讲究。有酒就喝，有敌便砍。（「坐下说话」是命令玩家，且与君主闲谈情形不合；改为对比燕、周礼数，更贴燕人口吻，也去掉指令。）

## chat · zhao · ["ruler"]

- ✎ 河北之地，寸土都是用血换的。你若有本事，孤不缺你一块地。
  → 河北寸土，皆是血换来的。你若有真本事，孤看得见。（原句「不缺你一块地」等于许诺土地，犯忌；改为只表态度。）
- ✎ 孤问你一句：跟着孤，你能拿多少颗人头回来？
  → 孤只问一句：上了阵，你砍得下几颗人头？（「跟着孤」是招揽入伙，越界；改为考较本事。）
