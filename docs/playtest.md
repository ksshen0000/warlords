# 试玩记录

对标《骑马与砍杀：战团》的成长节奏：无名小卒 → 剿匪、办差事攒钱和名望 → 当义从（佣兵）→ 向君主称臣 →
随元帅出征攻城 → 在朝议分封中争得封地。

## 怎么测

`server/tools/playbot.py`：一个照着「普通玩家」打法玩的机器人，战斗用自动结算，几分钟跑完游戏里的大半年，
记录里程碑。打法：进城招募 → 打听差事（剿匪、追剿匪帮、送信、运货）→ 打劫路的土匪 → 名望够了先签义从 →
再向（雇主国的）君主称臣 → 应召随军、随军围城。

```bash
cd server && .venv/bin/python -m tools.playbot --seed 3 --origin zhao --background lowborn --days 300
```

3D 战斗另外用客户端测：`./play.sh -- --battle-auto`（亲自上阵时由 AI 代你打，打完自动回大地图）。

大致流程（以种子 3 为例）：

1. 第 0 天：寒门武人，23 人，在洛阳。部队面板「下一步」建议进城打听差事；城主屈赫昭派了「追剿马贼」。
2. 前两个月：送信（一次 130–270 金）、运粮运盐（按市价收 + 180 金辛苦钱）、追剿流寇，偶尔被马贼截住。
   名望 30 大约在第 50–80 天。
3. 第 98 天签下蜀的义从契约（日薪 15 金），之后剿灭两处匪巢（每处 450 金、名望 +12）。
4. 名望过 120 后去找君主——**君主的行踪是公开的**（诸国面板总能看到），第 160 天向赵的天王称臣。
5. 第 163 天天王召集军团，召集令弹出，应召后一路随军（不会每碰一次面就弹遭遇菜单）。
6. 第 166 天随军围寿春，第 167 天城破，你是攻城功臣、进了分封候选；朝议最后把寿春给了天王本人。

节奏：称臣在第 68–245 天之间，大致对应战团里玩三到八个月游戏时间才被收为封臣。

## 2026-11-19 第 2 轮：第一次拿到封地（完整链条跑通）

种子 11，巴蜀 · 流民帅，360 天：

1. 第 0–28 天：送信、运铁、运木材，差事一件接一件（三十多件，四成是送信）；第 28 天签赵的义从。
2. 第 156 天向燕的大单于拓延烈称臣（名望 190 上下）。
3. 之后共应召随军 8 次。第 238 天随崔晏等人攻陷虎牢关——攻下后弹出「当面请封」，请了；
   **第 240 天：朝议决定把虎牢关封给你！**
4. 第 257 天又随军攻陷邺城，再次请封，第 259 天邺城也封给了你。
5. 之后两座城在战争中先后丢掉（被夺回 / 叛乱），360 天时封地为 0——战团里也是这样，守住封地是另一门功课。

这一轮之前，封地一直拿不到，依次找到并修了三处：功臣名单只取前 5 人而玩家排在最后（被截掉）→ 玩家排最前；
君主把城留给自己 → 君主自取的基础意愿从 8 降到 5（`fief_ruler_self`），没有封地的功臣加分；
战团式的「当面请封」→ 攻下城后弹出请封，候选标注「已当面请封」，投票加分（`fief_request_weight`）。

其他三局：两局称臣但 360 天内没赶上成功的攻城（随军时统帅兵败、或军团解散）；两局后期破产（机器人的理财太差：
军饷付不起又一直招兵）——这是机器人的问题，不是流程问题。

## 2026-11-20 第 3 轮：食邑、事件、封地事务（认为 OK）

四局 360 天，全部离线（0 档）。本轮新增：称臣时君主赐一个村子作**食邑**（每天交租）；大地图**小事件**（流民、逃兵、
疫病、设宴、名士、化缘、伤兵、山贼投诚、坞堡犒军、欠饷、同乡）；自己的城可以**处理封地事务**（留兵/抽兵、加固城墙、
开仓赈济），食邑可以修渠垦田。

种子 3 的经过很像战团：第 210–240 天被打得只剩光杆（0 人），靠食邑的租子和差事慢慢补回十来个人，
应召随军，跟着大军攻下蓟城——攻城后当面请封，朝议把蓟城封给了你；两个月后又随军攻下龙城，再次请封成功。
有了城以后收入猛涨（30 天从 3 千到 1.2 万金）。

事件节奏：每局一年 4–9 次，间隔至少 4 天；欠饷事件只在发不出饷时出现。

这一轮修掉的：机器人一直拿开局时的部队对象（被打光后不再更新）；机器人只肯向雇主国称臣（雇主远在千里外或好感不够时
永远等不到）——改成找任何肯收的君主；投诚、疫病事件在附近没有村镇时文字里会空出地名。

## 第 1 轮之后又修好的问题

| 问题 | 原因 | 修复 |
|---|---|---|
| 称臣后很少收到召集令 | 召集只在军团组建那一刻发，那时你常开着菜单 | 每天检查：本国有出征的军团、你还没被召过，就补发召集令（每个军团一次） |
| 随军攻下城，分封名单里却没有你 | 名单只取前 5 人，玩家被排在最后 | 玩家排在功臣最前 |
| 进了名单，城还是被君主拿走 | 君主给自己的分数和普通将军一样高 | 君主自取意愿降低；没有封地的功臣加分；攻下后可「当面请封」 |
| 亲自上阵的战报写「共 0 回合」 | 3D 战斗没有回合数据 | 显示「亲自上阵（3D 战场）」，不画回合曲线 |

## 这一轮发现并修好的问题

| 问题 | 原因 | 修复 |
|---|---|---|
| 部队在渡口、山口边卡住不动（玩家点建康会永远走不到） | 路标在 4 格内碰到目的地就直奔，不管隔着江；斜线擦过不可通行格子的角会漏检，被吸回原地来回抖 | 直线不通就沿流场走；直线检测加密；被挡时贴墙滑行；最后几步擦角就直接到达；去不了的巡逻点放弃重选 |
| 分封时玩家落选，服务器崩溃 | `grant_fief` 把候选人「player」当将军查 | 跳过玩家，并告诉玩家「这次没有得到封地」 |
| 被俘逃出后一兵一卒都没有，被土匪反复抓 | 没兵也会被打败俘虏 | 没兵时只被搜走钱财；身无分文、没兵的人土匪不理；逃出时有 5 个同乡跟着 |
| 运货差事暴利（运 9 份香料得 2524 金） | 赏金按市价 1.6 倍 | 只派日用货（粮、木、盐、铁、布），按市价收 + 固定辛苦钱；说明里写「哪座城有货、多远」 |
| 运货差事大多逾期 | 期限 10 天，大地图太远 | 14 天 |
| 匪巢被别人剿了算你失败、扣好感 | — | 改为「差事作罢」，不扣好感；同一处匪巢不会同时派两次 |
| 追剿马贼几乎不可能 | 马贼骑马比你快 | 追剿差事挑最慢的匪帮，期限 8 天 |
| 一个兵都没有也能签义从，日薪 0 | — | 至少 10 人才有人雇 |
| 称臣后不知道去哪打仗、拿不到封地 | 没有召集机制 | 元帅召集军团时召封臣「应召随军」，随军自动加入围城，城破即攻城功臣 |
| 名望够了却找不到君主 | 视野机制下远处君主行踪不明 | 君主行踪公开 |

## 还没解决 / 下一步

- **封地**：第 2 轮已经能拿到（称臣后约 80 天），但要看运气——随军的那支军团得真打下一座城。
- **封地之后**：已有守军调动、加固城墙、赈济、食邑修渠；还没有：城里建作坊/驿站、任命守将、税率。
- 机器人有钱也不扩军（种子 3 攒了 2.5 万金只带 16 人）——机器人的问题。
- 机器人只用自动结算；3D 亲自上阵的胜率、伤亡还要人来玩。
- 送信差事偏多（接力送信），名望增长主要靠剿匪；可以考虑更多样的差事（护送商队、征募新兵、收税）。
- 被俘逃脱后的处境仍然艰难（钱也会被搜走）——要靠差事和剿匪慢慢恢复，和战团差不多。
