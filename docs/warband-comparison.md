# 《战团》单机机制对照

对照原版《骑马与砍杀：战团》的单机战役，主要参考[官方手册](https://shared.cloudflare.steamstatic.com/store_item_assets/steam/apps/48700/manuals/PDX5505US_Warband_Manual_US.pdf?t=1728557946)第 4、5、7、9、11、12 章和 [TaleWorlds 的《战团》功能介绍](https://www.taleworlds.com/en/Games/Warband)。项目继续采用架空南北朝的地理、人物、兵种和制度。

| 功能 | 本项目现状 | 仍欠缺的部分 |
|---|---|---|
| 野战规模和战斗阶段 | 双方共享名额，默认 120 人、最多 150 人。按兵力和战术分配名额，阶段内分波增援，阶段间继承伤亡和生命，可以整队或撤离。 | 玩家成长中的战术和急救技能，按队伍顺序挑选优先上场兵种。 |
| 步战、骑战、远程 | 方向出招和格挡、盾挡箭、弓弩、马槊冲刺、马匹冲撞、跳跃、踢击、第一/第三人称。 | 投掷武器、战场拾取武器、盾耐久和破盾、独立马匹与上下马、战场行囊。 |
| 分队指挥 | 步射骑三队，支持追加选择、指定驻守地点、移动和疏密指令、停射。 | 自定义分队、按距离选择士兵、武器限制指令、上马和下马指令、队友识别旗标。 |
| 招募、晋升和同伴 | 城村招募，军饷、伤员和兵种分支晋升。酒肆里的 8 个具名同伴：随队作战（打倒只受伤）、可加点换装、提供队伍技能、日薪、喜恶与宿敌、士气低落会离队。 | 酒肆雇佣兵、招募俘虏和解救被俘士兵、同伴的成长对话与个人任务。 |
| 角色成长 | 地域和家世、名望、装备、坐骑、门第与官职。经验与等级、四项属性、14 项技能（含战术、寻路、侦察、医术、疗伤等队伍技能）、五种武器熟练度（亲自上阵命中即提高）。 | 更多技能（囚犯管理、说服、武器大师等）、按技能解锁的对话选项。 |
| 势力与政治 | 义从、称臣、随军、请封、封地经营，以及原有的朝议、外交、叛逃和王位继承。 | 玩家建立势力、独立后组织臣属、拥立其他继承人、联姻和宴会。 |
| 城镇、经济和差事 | 城镇/村庄/府衙/酒肆可步行，市场、兵器铺、招募、赎俘、领主委托，封地可经营。 | 潜入敌城和越狱救人、工商业投资、更多任务链与商旅角色。 |
| 围城 | 可亲自率军登城，也能从城头守城。城墙、垛口、云梯和马道影响交战，战果写回大地图。 | 攻城塔、破城后巷战及后续据点战斗。 |
| 擂台、练习和开局 | 城中单人擂台、下注、独立战斗场景。 | 多轮多队比武、自定义战斗界面、面向新玩家的训练和教学。 |
| 战役持续性 | 自动存档 + 5 个存档位，可随时读档；旧存档在新版本里自动补全字段。 | 存档改名、导出与云同步。 |

独立坐骑、战场拾取和城内巷战直接扩展已经可玩的 3D 战斗。角色等级、技能与存档适合先于具名同伴和自建势力落地。对照范围是单机玩法，官方多人模式单列于手册第 13 章。
